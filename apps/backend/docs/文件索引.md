## 文件優先級

---

## 文件選擇

不要無差別讀取所有文件。

根據問題選擇相關文件：

- 架構問題 → `architecture/`
- Canvas 問題 → `canvas/`
- Controller 問題 → `canvas/controller.md`
- State 問題 → `canvas/state.md`
- Action 問題 → `canvas/actions.md`
- API 問題 → `api/`
- 程式碼規範 → `development/coding-rules.md`

如果不確定應該查看哪份文件：

1. 先查看本文件。
2. 找出最相關的文件。
3. 再閱讀該文件。
4. 不要因為不確定而讀取整個 `docs/`。

# 文件維護規則

新增重要架構文件時，必須加入本索引。

修改架構或 API 行為時，如果現有文件已經描述該行為，
必須同步更新文件。

文件應該描述：

- 為什麼這樣設計
- 元件 / 模組的責任
- 可以怎麼使用
- 不應該怎麼使用

不要在文件中重複大量程式碼。

程式碼才是實際實作的最終來源。
