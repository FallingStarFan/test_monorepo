# 程式碼完整性與檢查

- 當我要求程式碼時，預設提供完整、可直接使用的程式碼。
- 不要省略必要的 import、type、interface、props、helper function、CSS 或設定。
- 如果需要修改多個檔案，完整列出所有需要修改的檔案。
- 不要使用 `...`、`// 其他程式碼` 等方式省略必要程式碼，除非我明確要求只看差異。
- 提供程式碼前，檢查 TypeScript 型別、import/export、React hooks、props、state、事件處理與元件 API。
- 檢查是否存在明顯的 TypeScript、React、runtime error。
- 檢查是否遺漏必要的 CSS、dependency 或設定。
- 如果已知前面的程式碼有錯誤，提供新版本時一起修正。
- 不要只加入新功能而保留已知錯誤。
- 不確定時不要猜測。
