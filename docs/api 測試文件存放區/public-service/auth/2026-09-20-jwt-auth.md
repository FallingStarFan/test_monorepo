# JWT Auth API 測試文件

## 測試資訊

- **Module:** `public-service/auth`
- **日期:** 2026-09-20
- **變更 Commit:** `feat(auth): replace session table with jwt`
- **測試者:** Git 使用者

## 受影響 API 或資料流程

| Method | Path / Flow | 說明 | 變更類型 |
|---|---|---|---|
| `GET` | `/auth/google/callback` | OAuth 成功後簽發 JWT cookie | 修改 |
| `GET` | `/auth/github/callback` | OAuth 成功後簽發 JWT cookie | 修改 |
| `POST` | `/auth/logout` | 清除 JWT HttpOnly cookie | 新增 |
| `GET` | `/auth/me` | 驗證 JWT cookie 並取得目前使用者 | 新增 |
| `N/A` | `AuthService.validateAccessToken` | 驗證 JWT，不查詢 sessions table | 修改 |

## 前置條件

- `JWT_ACCESS_SECRET` 與 `JWT_ACCESS_EXPIRES` 已設定。
- 測試資料包含可登入且狀態為 `ACTIVE` 的使用者。
- OAuth 測試需要有效的 Google / GitHub OAuth 設定。
- JWT 放在 `HttpOnly` cookie：`access_token`。
